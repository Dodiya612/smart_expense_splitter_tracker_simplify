# Smart Expense Splitter & Tracker
**Group No:** 28 | **Lab Group:** 4

## 3. Elicitation Techniques

### 3.1 Primary Stakeholders

| Stakeholder | Techniques | Description | How We Can Achieve It |
|---|---|---|---|
| **Individual Users** (Students, Working Professionals) | Surveys, interviews, user stories | Track personal expenses, set budgets, analyse spending | Online surveys and informal interviews with students and professionals to understand needs and daily challenges |
| **Group Users** (Friends / Roommates / Colleagues) | Focus group discussions, interviews | Share expenses, split bills, monitor group budgets, resolve discrepancies | Group discussions and interviews with student groups and working professionals to learn how they manage shared expenses and pain points |
| **Group Admin / Creator** | User interviews, scenario analysis | Create groups, manage members, set group settings, oversee shared expenses | Interview potential group leaders and analyse real-life scenarios to find features needed for group management |
| **Family / Household Users** | Interviews, contextual inquiry | Manage household expenses, shared accounts, family budgets | Interview households to understand spending patterns; design scenarios for real-world family use cases |

### 3.2 Secondary Stakeholders

| Stakeholder | Techniques | Description | How We Can Achieve It |
|---|---|---|---|
| **Company Owners / Management** | Stakeholder meetings, interviews | Product vision, profitability, scalability, long-term success | Discussions to understand business goals, target market and expectations |
| **Developers / IT Teams** | Requirement review, brainstorming sessions | Design, build, test, maintain the app | Requirement review sessions and regular brainstorming to align on technical needs and architecture |
| **Customer Support Team** | Interviews, user feedback analysis | Resolve issues, guide users, ensure smooth experience | Interview support staff and analyse common user queries to find needed tools/features |
| **GenAI Service** | Documentation review, expert consultation | Expense categorization, analysis, summaries | Review API docs and consult GenAI tools to understand capabilities and integration needs |
| **Bill/OCR Service** | Documentation review, experimentation | Extract expense details from bills/receipts | Research and test OCR services to evaluate accuracy and find the best fit |
| **Notification Service** | Documentation review, requirement analysis | Reminders and alerts for expenses, payments, budgets | Analyse requirements and explore notification services to identify needed features |
