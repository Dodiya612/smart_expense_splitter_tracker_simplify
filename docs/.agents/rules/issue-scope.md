# Coinscious Issue Scope Rule

Work only on the assigned issue. Inspect first, reuse working code, and make the smallest complete change. Do not add features, refactor unrelated code, duplicate functionality, or edit another member's work. Preserve existing uncommitted changes. If a required change affects a shared API, database schema, common component, or another member's implementation, coordinate first and stop if there is a conflict. Do not run destructive Git commands or commit/push/merge without authorization. Test relevant changes and report actual results honestly.
