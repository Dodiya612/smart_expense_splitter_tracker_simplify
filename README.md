# Smart Expense Splitter & Tracker

> A smart expense management application for tracking personal expenses,
> splitting group expenses, managing budgets, and gaining intelligent
> spending insights using Generative AI.

## 📌 About the Project

Managing personal and shared expenses can become difficult when multiple
people are involved. Tracking who paid, who owes whom, personal spending,
budgets, and recurring expenses can become time-consuming.

**Smart Expense Splitter & Tracker** aims to bring these activities into
a single platform.

The system is designed to help users:

- Track and categorize personal expenses
- Create groups and split shared expenses
- Track contributions, balances, and settlements
- Set budgets and receive budget alerts
- Analyze spending through charts and summaries
- Use Generative AI for intelligent expense analysis and categorization
- Upload bills or receipts and extract relevant information
- Manage recurring expenses
- Receive reminders and notifications

---

## ✨ Key Features

### 👤 Personal Expense Tracking

- Add, edit, delete, and view expenses
- Categorize expenses
- Maintain expense history
- Analyze personal spending patterns

### 👥 Group Expense Splitting

- Create and manage expense groups
- Add or remove group members
- Record shared expenses
- Split expenses between group members
- Track individual contributions
- Calculate who owes whom
- Track settlements

### 💰 Budget Management

- Create budgets for different categories
- Set weekly or monthly budget limits
- Monitor spending against budgets
- Receive alerts when approaching or exceeding limits

### 📊 Analytics & Insights

- Spending summaries
- Expense breakdowns
- Charts and visualizations
- Spending pattern analysis

### 🤖 Generative AI

GenAI will be used to provide intelligent features such as:

- Expense categorization
- Spending analysis
- Personalized expense summaries
- Spending insights and suggestions
- Natural-language interaction with expense information

### 🧾 Bill & Receipt Processing

Users will be able to upload bills or receipts and extract relevant
information such as:

- Merchant
- Amount
- Date
- Items
- Expense category

### 🔔 Notifications

The system is planned to provide notifications for:

- Pending payments
- Budget thresholds
- Recurring expenses
- Other relevant expense-related events

## 🎯 Project Goals

The main goals of the project are:

1. Simplify personal expense tracking.
2. Make group expense splitting easier and more transparent.
3. Help users understand their spending habits.
4. Reduce manual expense entry where possible.
5. Provide intelligent spending insights using GenAI.
6. Provide a secure, accurate, and user-friendly expense management system.

## 📋 Requirements

The project requirements include:

### Functional Requirements

- User Registration
- User Login & Session Management
- All-in-One Expense Tracking
- Data Analysis & Visualization
- Group Expense Splitting
- AI Advisor
- Customer Support
- Reminders & Notifications
- Parental Mode
- Budgeting & Alerts
- Recurring Expense Automation
- Bill/Receipt Scanning & Data Extraction
- Group Management
- Family/Household Expense Management
- System Administration

### Non-Functional Requirements

The system will consider:

- Usability
- Performance
- Security
- Reliability
- Maintainability
- Scalability
- Availability
- Data Privacy
- Accuracy
- Compatibility

### Domain Requirements

The system will enforce important rules including:

- Expenses must have valid positive amounts.
- Expenses should have appropriate categories.
- The total of shares in a split expense must correspond to the expense total.
- Only authorized group members can participate in group expenses.
- Users must have appropriate permissions to modify or delete expenses.
- Group balances and settlements must be accurately maintained.
- Budget calculations and financial calculations must be accurate.
- Financial information must only be accessible to authorized users.
